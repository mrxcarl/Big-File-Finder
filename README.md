# Big-File-Finder

A utility designed to help you identify and manage large files on your system.

## 🚀 Overview
**Big-File-Finder** (BFF) is a desktop tool that helps you find large files that might no longer be needed [2]. It provides an interactive interface to scan folders, view results, and manage files directly.

## ✨ Features
*   **File Identification:** Quickly scan directories to find large files [2].
*   **Interactive Management:**
    *   **Open Directory:** Quickly jump to the location of a found file [1].
    *   **Copy Path:** Copy the full file path to your clipboard with one click [1].
    *   **Delete File:** Remove large files directly from the application [1].
*   **Status Tracking:** View real-time status updates and total folder sizes during the scanning process [1].
*   **User Interface:** Features a custom-branded interface with a "JethroTeK" credit [1].

## 🛠️ Technical Details
The application is built using **Tkinter** for the graphical interface and includes a custom right-click context menu for quick actions [1].

## 🚀 Installation & Usage
1. Clone the repository.
2. Run `bff.py` to launch the application.
3. Use the interface to select folders and scan for large files.
